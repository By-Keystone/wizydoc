¿Olvidaste tu contraseña?

Prototipo del flujo de recuperación: login, pedir el enlace, los correos y crear la contraseña nueva. Los datos son de ejemplo.

Casos

Recorre el flujo tocando dentro del teléfono: «¿Olvidaste tu contraseña?» → «Enviar enlace» → abre el correo → «Crear contraseña nueva» → «Guardar contraseña».

Qué propone este mockup
  1. Siempre la misma respuesta. «Revisa tu correo» sale igual exista o no la cuenta. Muestra el correo escrito para que la persona note si lo escribió mal.
  2. El enlace dura 1 hora y sirve una vez. Lleva el token después de #, que no llega a ningún servidor ni log. Por eso «Este enlace ya no sirve» aparece al guardar si venció o ya se usó, y al abrir si está incompleto.
  3. Al guardar se cierran todas las sesiones y se vuelve al login con el aviso verde. No inicia sesión sola.
  4. Invitado sin contraseña: no recibe el correo de recuperación sino «Tu invitación a WizyDoc sigue pendiente», con el enlace de su invitación o, si venció, con qué hacer. En pantalla no cambia nada.
  5. Correo sin confirmar: recibe el de recuperación; al crear la contraseña queda confirmado.
  6. Igual para ADMIN, DOCTOR y USER, y en todos los planes: no hay 403 ni 402.
